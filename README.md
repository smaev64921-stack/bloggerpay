# BloggerPay

Биржа рекламы у блогеров: рекламодатель находит блогера, деньги
замораживаются на счёте сделки и уходят исполнителю после выполнения
работы. Комиссия со сделки — 0%, сервис зарабатывает 4% при выводе.

Открывается ссылкой из телеграм-бота — обычным сайтом в браузере.

## Что в репозитории

| Файл / папка | Что это |
|---|---|
| `bloggerpay-1008-v100.html` | само приложение — один файл, без сборки |
| `onboarding.html` | знакомство при первом входе, 4 экрана |
| `privacy.html` | политика конфиденциальности (нужна для проверки Google и TikTok) |
| `sw.js` | офлайн-режим |
| `netlify.toml` | заголовки, если раздавать сайт отдельно (Netlify) |
| `server/` | сервер: раздаёт сайт, ведёт деньги и держит бота |

Инструкции: **`ВЫКЛАДКА.md`** (как поднять), `ПОДКЛЮЧЕНИЕ-СОЦСЕТЕЙ.md`
(ключи TikTok и YouTube), `ЧТО-ГДЕ.md` (карта проекта).

## Запуск на хостинге

Сайт, касса и телеграм-бот работают **одним процессом**. Хостинг даёт адрес —
по нему открывается сайт, и на него же ведёт кнопка из бота. Отдельный
хостинг для сайта не нужен.

**Команда запуска:**

```bash
npm start
```

**Две переменные окружения** — в панели хостинга:

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен у [@BotFather](https://t.me/BotFather) → `/mybots` → ваш бот → API Token |
| `PUBLIC_URL` | адрес, который выдал хостинг, по `https` — например `https://bloggerpay.up.railway.app` |

Всё. Бот на `/start` пришлёт сообщение с кнопкой «🌐 Открыть BloggerPay»,
она откроет сайт в браузере телефона.

**Нужен Node 22.5 или новее.** База встроена в сам Node (`node:sqlite`) и
появилась только в 22.5 — на Node 20 сервер падает сразу с «No such
built-in module: node:sqlite». В корне лежит `Dockerfile`, который уже
указывает Node 22: если хостинг умеет собирать по нему, включите это. Если
версия задаётся в панели — поставьте 22+.

Несколько важных мелочей:

- **`PUBLIC_URL` обязателен и по HTTPS.** Через приложение идут пароли и коды
  из писем — по http бот откажется стартовать. Локально (`localhost`,
  `192.168.*`) http разрешён, там это безопасно.
- **Бот не роняет сайт.** Если токен не подошёл, сервер продолжит раздавать
  сайт, а причину напишет в консоль.
- **Порт** сервер берёт из `PORT`, если хостинг его задаёт.
- Если с сервера не открывается `api.telegram.org` — так бывает у хостингов
  в России — пропишите `TG_API_BASE` с адресом прокси.

Нужны только эти две переменные. Всё остальное (`server/.env.example`)
включает дополнительные возможности: настоящие платежи, письма,
подтверждение каналов.

## Быстрый старт

Приложение — статический файл, его достаточно открыть или положить на любой
хостинг. Без сервера оно работает в тестовом режиме: данные живут в браузере.

Сервер (нужен Node 22.5+, зависимостей нет):

```bash
cd server
cp .env.example .env      # заполнить BOT_TOKEN и PUBLIC_URL
cd .. && npm start        # сайт, касса и бот — одним процессом
```

Сайт откроется на `http://127.0.0.1:8090`. Бота можно запустить и отдельно —
`npm run bot`, — но обычно это не нужно.

Админ-панель владельца — `/admin` на адресе сервера (прежний адрес
`/operator` тоже открывает её): выплаты, проверка личности, спорные деньги,
пользователи, каталог, поломки, площадки и журнал действий. В мини-аппе
админки больше нет — всё здесь, и всё с сервера.

## Проверки

```bash
cd server
node test-scenario.mjs    # сделка, вывод, дыры из аудита
node test-partial.mjs     # бюджет кампании на нескольких блогеров
node test-disputes.mjs    # раздел спорных денег арбитром
node test-kyc.mjs         # проверка личности оператором
node test-pay.mjs         # режимы кассы и предохранители пополнения
node test-verify.mjs      # подтверждение каналов TikTok/YouTube
node test-bot.mjs         # разговор бота (на заглушке, без Телеграма)
```

Всего 152 проверки.

## Как устроены деньги

1. **Баланс не хранится** — он считается как сумма журнала операций.
   Расхождение невозможно по построению.
2. **Журнал только растёт.** Отмена — это встречная запись, а не правка.
3. **Одна операция проводится один раз** — у каждого денежного запроса есть
   ключ идемпотентности.

Сверка видна оператору: внесено − выплачено = столько-то в системе. Если
равенство разошлось, полоса краснеет.

## Безопасность

**`server/.env` не входит в репозиторий** — там ключ оператора, токен бота
и ключи платёжной кассы. Если такой файл случайно попал в публичный
репозиторий, удалить коммит недостаточно: ключи нужно перевыпустить.
